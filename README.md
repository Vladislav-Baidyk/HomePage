# News Homepage 📰✨

This is a solution to the [Frontend Mentor challenge](https://www.frontendmentor.io/challenges/news-homepage-H1r1S1bBq). The project is a responsive homepage for a news site, built with React and focused on clean layout and mobile-first design.

## ✨ Features

- **Responsive Layout:** Perfectly adapted for desktop and mobile (max-width: 480px) using CSS Media Queries.
- **Dynamic Mobile Menu:** Interactive sidebar menu for mobile users.
- **Data-Driven:** Content is managed via a JSON configuration for easy maintenance.
- **Modern UI:** Built with functional components and React hooks (`useState`).

## 🔧 Technologies Used

- **React** (Vite/CRA)
- **CSS3** (Custom properties, Flexbox, Media Queries)
- **JSON** (For managing image paths and assets)
- **HTML5** (Semantic tags like `<picture>`, `<nav>`, `<main>`)
